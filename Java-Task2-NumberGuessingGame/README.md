Number Guessing Game

Project Overview

A Java-based number guessing game with a graphical user interface. The player tries to guess a randomly generated number within a limited number of attempts.

Features

- Easy, Medium, and Hard difficulty levels
- Random number generation
- Hints when the guess is too high or too low
- Limited attempts based on difficulty
- Win and lose messages
- Play Again option
- Score tracking

Technologies Used

- Java
- Java Swing
- Eclipse IDE

How to Run

1. Install a compatible Java Development Kit (JDK).
2. Open the project in Eclipse.
3. Ensure the source file is named "NumberGuessingGame.java".
4. Run "NumberGuessingGame.java" as a Java application.
