Online Reservation System

Project Overview

A Java desktop application for booking, viewing, and cancelling train reservations.

Features

- Login validation
- Passenger and train details entry
- Automatic PNR generation
- Reservation lookup using PNR
- Reservation cancellation
- MySQL database integration

Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Eclipse IDE

Database Setup

1. Install and start MySQL.
2. Create a database named "reservation_db".
3. Create the required "users" and "reservations" tables.
4. Set the "MYSQL_PASSWORD" environment variable on your computer.
5. Configure MySQL Connector/J in Eclipse.

Do not upload database passwords or real passenger information.

How to Run

1. Import the project into Eclipse.
2. Configure your MySQL connection.
3. Ensure the database and tables exist.
4. Run "Main.java".
